# The First Telling

A focused visualization of character relationships, actions, and utterances in the opening frame narrative of The Arabian Nights, based on two research documents.

By **Zahra Zandiyeh**.

[Visit the exhibition](https://zandiyeh.art/digital-humanity/projects/the-first-telling/) · [All four projects](https://zandiyeh.art/digital-humanity/projects/)

## Repository scope

This repository shares a snapshot of the exhibition’s HTML, CSS, JavaScript, and available structured research data. Image assets, fonts, private documents, local tooling, and deployment credentials are not included. Some pages reference those omitted assets; use the live exhibition for the complete visual experience.

## Reading the code

Start with `index.html`. Other HTML files are chapters or analysis views. JavaScript implements the interactions; JSON and CSV files hold the project’s coded data and references where present. The First Telling also provides a Gephi network export. Counts describe the coded evidence and consulted editions, rather than all versions of the tales.
